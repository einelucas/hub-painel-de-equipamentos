# Documentação — Painel de Equipamentos

Este diretório descreve a base técnica e o primeiro fluxo funcional do módulo.

- `arquitetura.md`: organização do frontend, backend e persistência.
- `autenticacao.md`: OIDC/Keycloak e autenticação de desenvolvimento.
- `api.md`: endpoints compartilhados disponíveis nesta etapa.
- `banco-de-dados.md`: schema inicial e migrations.
- `desenvolvimento.md`: comandos e fluxo local.
- `modulos.md`: módulos existentes, incluindo o domínio de equipamentos (catálogos, equipamentos, painel).
- `etapa-01-primeiro-fluxo.md`: implementação integrada da Etapa 1, validações e pendências.
- `etapa-02-workflow-aquisicao.md`: máquina de estados 0–8, processos de aquisição, reabertura e pendências.
- `etapa-03-dashboard-navegacao-filas.md`: navbar, Dashboard Geral, filtros globais e filas por área.
